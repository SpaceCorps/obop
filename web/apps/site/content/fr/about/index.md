## Ce que nous construisons

Une suite de gestion modulaire, dans l'esprit des grands ERP tout-en-un, mais ouverte, portable et prête pour les agents IA dès le départ. Parmi ses applications intégrées figurent les contacts, les produits, le CRM, les ventes, la facturation et les connecteurs (les six qui ont une page d'application), et elle propose 24 paquets fournis (comptabilité, stocks, production, RH, projets, point de vente, commerce en ligne, site web, marketing par e-mail, assistance, documents et d'autres) qui sont encore en bêta ou expérimentaux.

obop est une réécriture « clean room » d'idées que les logiciels de gestion ont éprouvées pendant des décennies. Il ne copie le code de personne.

## Principes

- **Une entreprise, une plateforme.** Un seul modèle de données pour toutes les applications : rien à raccorder à la main.
- **Les agents sont des utilisateurs à part entière, et limités.** Jetons à périmètre limité, données personnelles masquées, et l'approbation d'une personne pour chaque suppression et pour les étapes qu'un module signale comme soumises à approbation.
- **Ouvert et portable.** Le code source est public, il fonctionne sur PostgreSQL, et les données d'une entreprise lui appartiennent.
- **Honnête.** Nous disons ce qui est réalisé et ce qui ne l'est pas. Pas de clients, de citations ni de chiffres inventés : ce site n'en contient aucun, car il n'y a encore rien de réel à montrer.
- **Langage clair.** La documentation et l'interface disent ce qu'elles veulent dire.

## Qui le construit

obop est construit par [SpaceCorps](https://github.com/SpaceCorps). Le code, les décisions et la feuille de route se trouvent dans le [dépôt](https://github.com/SpaceCorps/obop).

## Technologie

Le backend est en Rust. Les applications web utilisent Vite+ et React. Ce site web est un site statique généré avec VitePress à partir de Markdown et d'un système de design partagé. L'interface et les pages principales sont disponibles en sept langues (traduction automatique) ; les autres pages affichent le texte anglais.
