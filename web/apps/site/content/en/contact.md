| For | Where |
|---|---|
| Bug reports and feature requests | [GitHub issues](https://github.com/SpaceCorps/obop/issues) |
| Questions and ideas | The [community forum](/about/community/) |
| Security vulnerabilities | A private [GitHub security advisory](https://github.com/SpaceCorps/obop/security/advisories/new). See [Security](/security/). |
| Privacy questions about this website or the hosted beta | Open an issue without personal data and say you have a privacy question; we will move it to a private channel. |
| Press, partners, commercial questions | Open an issue titled "Commercial" with a way to reach you that you are happy to publish, or use the repository's contact details. |

We will add a mailbox here when the project has one. Until then, please do not send sensitive information through public channels.

## What helps us answer quickly

- The version of obop and how you run it (hosted beta, Docker, local).
- What you did, what you expected and what happened.
- Logs with personal data, tokens and passwords removed.
