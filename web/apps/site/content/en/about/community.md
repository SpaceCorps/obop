## Where to ask

A control plane (`obop platform serve`) includes a forum at `/community/` for its own users. Questions, ideas, bug reports and feature requests for the obop project go to [GitHub issues](https://github.com/SpaceCorps/obop/issues).

## Ground rules

1. **Be kind and assume good faith.** Disagree with ideas, not people.
2. **Be specific.** Say what you did, what you expected and what happened. Include the version and how you run obop.
3. **Never post personal data or secrets.** No customer details, no agent tokens, no passwords, no database URLs. Redact logs before you paste them.
4. **Security problems are not public posts.** Report vulnerabilities privately; see [Security](/security/).
5. **No advertising or spam.** Relevant links to your own marketplace or app are welcome when you say it is yours.
6. **Stay on topic**, and use the language you are most comfortable in; English is the common one.

Maintainers may hide comments or close issues that break these rules.

## Contribute

- **Report bugs and ideas** as GitHub issues.
- **Write a package.** The [module manifest reference](/docs/reference/module-manifest/) shows how, and you can publish it in [your own marketplace](/marketplace/).
- **Improve the documentation.** Every docs page has an _Edit this page on GitHub_ link.
- **Review a translation.** The translations of this website are machine-drafted and need native review; see the repository's site documentation.
