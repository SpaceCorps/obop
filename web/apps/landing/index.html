Built for the way work happens now

Agents are first-class

Every action is available on the REST API, as an MCP tool and on the command line, from the same definition. An agent gets exactly the permissions you grant, never more than its owner.

Agents propose. Humans approve.

Sensitive data stays private

Every field has a data class. Agents see masked values or nothing at all for personal and financial data, and can write tokens back without ever seeing the real value.

Masking by default

One data model

Apps are modules on one registry, so a contact is the same contact in CRM, sales and invoicing. Permissions, audit and the API come with every model you add.

PostgreSQL underneath

Install what you need. Upload what you build.

Admins add modules in a click from the marketplace, or upload their own package. A module describes its models, fields and workflow in one file, and instantly gets the API, the agent tools, the permissions and the privacy rules like everything else.

  • One-click install, upgrade and removal, with your data kept
  • Custom modules for a single customer, reusing a shared core
  • Checked on install: every field needs a data class and a permission group
[module]
id = "fleet"
name = "Fleet"

[[model]]
name = "fleet_vehicle"
read_group  = "fleet.user"
write_group = "fleet.manager"

  [[model.field]]
  name  = "driver"
  class = "internal"
  personal_data = true

  [[model.action]]
  name  = "dispatch"
  field = "state"
  from  = "available"
  to    = "in_service"
